# elaina listen（轻语听书）

elaina listen 是面向 Android 的中文听书项目，目标设备为 realme GT7。当前版本包含 P0 工程初始化、P1 基础界面、P2 Kokoro-82M 离线语音合成和 P3 双女声试听。

从首页或设置打开「声音选择」，可试听默认的小妮（1.0×）和小小（1.05×）。可输入自己的文字，留空则使用同一段示例。应用保存默认音色。模型随 APK 安装，手机首次试听也可完全离线。

浏览网页、正文提取、章节播放器和收藏功能由后续阶段接入。
