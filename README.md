# elaina listen（轻语听书）

elaina listen 是面向 Android 的中文听书项目，目标设备为 realme GT7。当前完成范围为 P0 工程初始化和 P1 基础界面，包含首页、浏览器、播放器、声音选择、收藏和设置六个页面。

浏览网页、朗读、播放及收藏能力将在各自阶段接入。当前应用可以打开各页面和返回，界面会说明尚未开放的能力。
