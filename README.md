# elaina listen（轻语听书）

elaina listen 是面向 Android 的中文听书项目，目标设备为 realme GT7。当前版本完成 P0 至 P6，支持在应用内浏览 HTTPS 网页、提取正文，并使用本地 Kokoro-82M 和 Media3 朗读。

从首页或设置打开「声音选择」，可试听默认的小妮（1.0×）和小小（1.05×）。可输入自己的文字，留空则使用同一段示例。应用保存默认音色。模型随 APK 安装，手机首次试听也可完全离线。

在「浏览器」中输入网址，打开网页后点「提取正文」。正文页面可从头朗读，也可长按任一段落从该段开始。自动提取失败时，可长按原网页选择文字并朗读，或复制到「粘贴朗读」。

「播放器」支持暂停与继续、前后跳过 10 或 30 秒、拖动已合成音频的进度、0.8～2.5 倍速、切换章节和音色。自动翻页、后台播放及收藏在后续阶段接入。
