# elaina listen

elaina listen 是面向 Android 的中文听书项目，目标设备为 realme GT7。当前版本实现 P0 至 P10，支持在应用内浏览 HTTPS 网页、提取正文，并使用内置 Matcha 或 Azure Speech 合成语音，通过 Media3 朗读。

在「声音选择」可选择「Matcha 中文女声」，安装后即可离线试听和朗读。配置 Azure 区域和密钥后，可继续使用晓晓与云希。

在「浏览器」的可收起地址栏输入网址，打开网页后点「提取正文」。正文页面可从头朗读，也可长按任一段落从该段开始。自动提取失败时，可长按原网页选择文字并朗读，或复制到「粘贴朗读」。

打开可阅读的 Pixiv 小说后点「提取正文」，应用读取网页提供的全文数据并显示总字数。作者设置的页分隔在应用内连续朗读。全文读取遇到错误时，可明确选择预览当前可见的内容。普通网页可在朗读结束后自动操作可识别的下一页控件。

「播放器」支持暂停与继续、前后跳过 10 或 30 秒、拖动已合成音频的进度、0.8～2.5 倍速、切换章节和音色。播放时打开「查看原文」可看到当前句的黄色高亮，拖动进度后会定位到对应句。睡眠定时支持 15～120 分钟、延长、取消和听完本章停止。播放器从开始生成音频时显示本页预计总时长，按实际音频和倍速更新。可在设置将朗读和试听的每段上限设为 80～200 字。读完章节后，播放器会等待一秒并尝试继续下一章，或打开同站的「下一页」「下一章」链接。可在设置关闭自动翻页。切到后台或锁屏后，使用系统媒体控件暂停和继续。设置中可开启与其他应用同时播放。最近一次朗读的正文和位置会保存到本机，可在首页选「继续上次听书」。

竖屏播放器把进度条和播放键固定在底部。原文、预计时长和睡眠定时在上方，睡眠定时可以直接在卡片上滑动设置。横屏或窗口高度受限时，播放控件与正文工具一起滚动。

在正文或播放器点「添加收藏」。听书收藏支持文件夹管理，点卡片可查看原文。浏览器首页按置顶和收藏时间展示网址卡片，支持搜索、长按和站点图标。浏览器最多同时打开五个标签页。

在正文、播放器或收藏中点「加入听单」。打开底部的「听单」，可点篇目播放、上移、下移或移出。听单保存顺序和每篇进度。「整套系列加入听单」会按 Pixiv 目录加入当前可访问的篇目。设置中可以单独开启 Pixiv 系列连读。

设置提供四种主题色，深色模式可跟随系统、手动开或手动关。「一键清理」会报告可清理和已释放的空间。已合成的 Azure 音频可离线重听，缓存上限可在设置中调整。

可在「设置 → Azure 云端语音」保存 Microsoft Azure Speech 资源的区域和密钥，随后试听或选择 Azure 晓晓与云希。密钥在应用私有存储中加密保存，可更换或移除。云端音色使用时会发送文本并可能产生 Azure 费用。[Azure 音色列表](https://learn.microsoft.com/zh-cn/azure/ai-services/speech-service/language-support?tabs=tts)

可在「设置 → MCP 连接」按需授权电脑上的 MCP 客户端操作应用浏览器、播放器和收藏。[MCP 连接方法](docs/mcp.md)
