# elaina listen

elaina listen 是面向 Android 的中文听书项目，目标设备为 realme GT7。当前版本实现 P0 至 P10，支持在应用内浏览 HTTPS 网页、提取正文，并使用 Azure Speech 和 Media3 朗读。

配置 Azure 区域和密钥后，可在「声音选择」试听晓晓与云希并设置默认音色。合成需要联网。

在「浏览器」的可收起地址栏输入网址，打开网页后点「提取正文」。正文页面可从头朗读，也可长按任一段落从该段开始。自动提取失败时，可长按原网页选择文字并朗读，或复制到「粘贴朗读」。

「播放器」支持暂停与继续、前后跳过 10 或 30 秒、拖动已合成音频的进度、0.8～2.5 倍速、切换章节和音色。播放时可打开「查看原文」并定位正在朗读的段落。播放器从开始生成音频时显示本页预计总时长，按实际音频和倍速更新。可在设置将朗读和试听的每段上限设为 80～200 字。读完章节后，播放器会等待一秒并尝试继续下一章，或打开同站的「下一页」「下一章」链接。可在设置关闭自动翻页。切到后台或锁屏后，使用系统媒体控件暂停和继续。设置中可开启与其他应用同时播放。最近一次朗读的正文和位置会保存到本机，可在首页选「继续上次听书」。

在正文或播放器点「添加收藏」。听书收藏支持文件夹管理，点卡片可查看原文。在浏览器直接收藏当前网址，网址在浏览器首页打开。浏览器最多同时打开五个标签页。

可在「设置 → Azure 云端语音」保存 Microsoft Azure Speech 资源的区域和密钥，随后试听或选择 Azure 晓晓与云希。密钥在应用私有存储中加密保存，可更换或移除。云端音色使用时会发送文本并可能产生 Azure 费用。[Azure 音色列表](https://learn.microsoft.com/zh-cn/azure/ai-services/speech-service/language-support?tabs=tts)

可在「设置 → MCP 连接」按需授权电脑上的 MCP 客户端操作应用浏览器、播放器和收藏。[MCP 连接方法](docs/mcp.md)
